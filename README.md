# 个人导航站

本地个人工具导航 + 后端进程管理器。把散落的本地小工具整合到一个页面：
点击卡片 → 后台静默执行启动命令（如 `ammp`、`tblw`、`npm run dev`）→ 等待端口就绪 → 自动打开页面。
已在运行的进程**不会重复启动**，并可在「进程管理」页统一停止。

## 快速开始

**日常使用：直接敲 `pnw`**（全局命令，装在 `%USERPROFILE%\bin\pnw.cmd`，内容见下方「安装 pnw 快捷命令」）：

```
pnw          无窗口静默启动服务（已在运行则直接打开浏览器）
pnw stop     停止导航站服务本身（不会连带杀掉工具后端进程）
```

开机已自动启动（计划任务 `PersonalNav`，登录时经 `pythonw` 无窗口拉起）；
移除自启：运行 `uninstall_autostart.cmd`，重新安装：`install_autostart.cmd`。

双击 `start.bat` 也可以（首次运行会自动创建 venv 并安装依赖，带控制台窗口，便于看日志）。

### 安装 pnw 快捷命令（可选，换机重装用）

仓库根目录的 `pnw.cmd` 是模板：复制到 PATH 里的目录（推荐 `%USERPROFILE%\bin`），
并确认其中的 `PNW_DIR` 指向你的项目路径：

```bat
copy pnw.cmd "%USERPROFILE%\bin\pnw.cmd"
```

手动启动：

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8790
```

换端口：设置环境变量 `NAV_PORT`（`pnw`、自启任务、`start.bat` 都遵循它，默认 8790）。
`pythonw` 静默方式下服务日志写入 `logs\server.log`。

## 核心机制

### 防重复启动（三重保险）

1. **端口探测**：工具配置了端口时，先探测 `127.0.0.1:port` 是否已有监听。
   你在终端手动启动的进程也会被识别，登记为「外部进程」，绝不重复拉起。
2. **PID 记录**：导航站自己启动的进程记录 PID + 进程创建时间（防 PID 复用误判），
   存活即不重启。无端口的 CLI 工具依赖此判定。
3. **互斥锁**：启动动作按工具加锁，双击/并发请求不会拉起两个实例。

### 静默运行与生命周期

- 子进程以 `CREATE_NO_WINDOW | CREATE_NEW_PROCESS_GROUP` 创建，无窗口、
  有独立隐藏控制台；**导航站退出/关闭控制台不影响工具后端继续运行**，
  重新打开导航站会通过 PID/端口自动重新识别（周期校准，默认 8 秒）。
- stdout/stderr 重定向到 `logs\` 下的日志文件，页面可实时查看尾部。

### 停止策略（优雅优先）

1. 工具配置了「自定义停止命令」→ 执行它；
2. 否则发送 `CTRL_BREAK` 优雅停止，等待 3 秒；
3. 仍未退出 → `taskkill /T /F` 强制结束整棵进程树。

外部进程（非导航站启动）跳过 1、2（避免向你的终端控制台发控制事件），直接强杀。

## 工具字段说明

| 字段 | 说明 |
|---|---|
| 名称 / 分组 / 图标 / 描述 | 展示用；分组是自由文本，填新分组名即自动建组 |
| 打开地址 URL | 点卡片时打开的地址；留空 = 仅启动不打开（纯 CLI 工具）。**纯链接工具（无启动命令）点卡片/打开直接开网页，与运行状态无关**；没写协议前缀（如 `github.com`、`127.0.0.1:8000`）会自动补 `http://` |
| 启动命令 | 后台静默执行的命令行（经 `cmd /c`，支持 npm 等批处理入口）；留空 = 纯链接 |
| 工作目录 | 启动命令的执行目录；留空继承导航站目录 |
| 服务端口 | 用于就绪探测与防重复启动；纯链接工具可不填 |
| 启动超时 | 等待端口就绪的最长时间（默认 30 秒），超时不算失败，进程仍保留 |
| 无端口时等待 | 无端口工具启动后确认进程存活的时间（默认 1 秒） |
| 自定义停止命令 | 可选；优先于默认停止方式（如工具自带 `xxx shutdown`） |
| 排序值 / 启用 | 排序小的在前；禁用后不在导航页显示（管理页仍可见） |

## 目录结构

```
app/            FastAPI 后端（db.py 存储 / process_manager.py 进程核心 / api.py 路由）
static/         无构建步骤的原生前端（index.html / app.js / style.css）
data/nav.db     SQLite 数据库（工具配置、进程记录、设置）
logs/           各进程的运行日志
```

## API 一览（本机使用）

```
GET    /api/tools                     工具列表（含运行状态）
POST   /api/tools                     新增
PUT    /api/tools/{id}                更新
DELETE /api/tools/{id}                删除（会先尝试停止其进程）
POST   /api/tools/{id}/start          确保运行（已在运行则跳过，阻塞至就绪/超时）
POST   /api/tools/{id}/stop           停止（优雅优先）
GET    /api/tools/{id}/logs           最近一次运行的日志尾部
GET    /api/processes                 运行中 + 历史进程记录
GET    /api/processes/{id}/logs       指定进程记录的日志
```

## 安全说明

- 服务仅绑定 `127.0.0.1`，无鉴权。**请勿直接暴露到局域网/公网**——管理界面可以
  配置并执行任意本机命令。如需远程访问，请在前面加带认证的反向代理。
- 「启动命令」等配置等同于你自己在终端输入的命令，请只添加自己信任的工具。

## 扩展点

- `tools` 表预留 `extra` JSON 字段，可放任意每工具的自定义配置；
- `settings` KV 表可存全局开关（如主题、开机自启动策略）；
- 前端为无构建原生前端，新增页面能力直接改 `static/app.js` 即可。
